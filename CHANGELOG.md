# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project structure with modular architecture
- Attention-enhanced LSTM model with Bahdanau and Luong attention
- Model factory supporting LSTM, GRU, and Transformer architectures
- Hyperparameter optimization with Optuna integration
- SHAP-based model interpretability
- FastAPI web API with comprehensive endpoints
- Pydantic schemas for request/response validation
- Comprehensive test suite with pytest
- Performance benchmarking suite
- GitHub CI/CD pipeline with linting, testing, and deployment
- Automated releases with semantic versioning
- Docker containerization support
- Documentation and contribution guidelines
